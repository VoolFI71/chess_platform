# Python POST Requests Script

Скрипт для отправки множественных POST запросов с детальной статистикой.

## Описание

Скрипт отправляет **1000 POST запросов** на указанный эндпоинт с заданной полезной нагрузкой и собирает статистику выполнения.

## Установка

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

## Запуск

```bash
python script.py
```

## Конфигурация

В начале файла `script.py` находятся основные параметры:

```python
URL = "swaga/ajax.php"  # URL эндпоинта
TOTAL_REQUESTS = 1000    # Количество запросов

PAYLOAD = {
    "sessid": "0ab3ad9777cd6e898214e8d8abe761c1",
    "action": "getPrice",
    "tariff": "241",
    "club": "449539"
}
```

Вы можете изменить эти параметры под свои нужды.

## Возможности

- ✅ Отправка множественных POST запросов
- ✅ Прогресс выполнения в реальном времени
- ✅ Детальная статистика:
  - Количество успешных/неудачных запросов
  - Процент успеха
  - Время выполнения
  - Запросы в секунду
  - Среднее/мин/макс время ответа
- ✅ Обработка ошибок (Timeout, ConnectionError и т.д.)
- ✅ Сохранение результатов в JSON файл
- ✅ Прерывание по Ctrl+C

## Настройка задержки

Для снижения нагрузки на сервер раскомментируйте строку в коде:

```python
# time.sleep(0.01)  # Задержка 10мс между запросами
```
