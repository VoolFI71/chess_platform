# Программы для численного интегрирования и решения ОДУ

## Описание

Данный проект содержит две программы для работы с библиотекой SciPy:

1. **integrals.py** - программа для численного вычисления 15 определённых интегралов
2. **ode_solver.py** - программа для численного решения 15 обыкновенных дифференциальных уравнений

## Требования

Для работы программ необходимы следующие библиотеки Python:
- numpy
- scipy
- matplotlib

Установка зависимостей:
```bash
pip install numpy scipy matplotlib
```

## Запуск

### Вычисление интегралов

```bash
python integrals.py
```

Программа выведет в консоль:
- Численные результаты для каждого интеграла
- Точные решения (где возможно)
- Оценки погрешности
- Относительные ошибки
- Сводную таблицу результатов

### Решение ОДУ

```bash
python ode_solver.py
```

Программа создаст 15 графиков (по одному для каждой задачи) с именами:
- `ode_problem_1.png`
- `ode_problem_2.png`
- ...
- `ode_problem_15.png`

Каждый график содержит:
- Сравнение численного и точного решений
- График относительной ошибки
- График абсолютной ошибки

Также программа выведет в консоль информацию о решении каждой задачи.

## Структура программ

### integrals.py

- Определяет 15 функций для интегрирования
- Вычисляет точные решения (где возможно аналитически)
- Сравнивает численные и точные результаты
- Использует `scipy.integrate.quad` для численного интегрирования

### ode_solver.py

- Определяет 15 ОДУ с начальными условиями
- Преобразует ОДУ второго порядка в системы первого порядка
- Решает задачи численно с помощью `scipy.integrate.solve_ivp`
- Сравнивает с точными решениями (где возможно)
- Строит графики сравнения и ошибок

## Примечания

- Для некоторых интегралов и ОДУ точные аналитические решения сложны или недоступны. В таких случаях используются высокоточные численные решения как эталон.
- Программы используют настройки шрифтов для корректного отображения математических символов в графиках.
