# План доработки страницы задач (Tasks Page Redesign)

## 📋 Общая концепция
Создать современную, интуитивную и функциональную страницу для решения шахматных задач с улучшенным UX/UI, расширенной статистикой и дополнительными возможностями.

---

## 🎨 1. ДИЗАЙН И ВИЗУАЛЬНОЕ ОФОРМЛЕНИЕ

### 1.1. Редизайн карточки задачи
- [ ] **Улучшенный заголовок карточки**
  - Более выразительный заголовок с иконкой
  - Градиентный фон для активной задачи
  - Анимация появления при загрузке новой задачи

- [ ] **Информационная панель**
  - Карточки с метриками (рейтинг, ходы, тема, сложность)
  - Иконки для каждой метрики
  - Цветовое кодирование сложности
  - Прогресс-бар решения задачи (сколько ходов сделано)

- [ ] **Статус задачи**
  - Визуальные индикаторы состояния (ожидание, решение, успех, ошибка)
  - Анимированные уведомления
  - Цветовая индикация результата

### 1.2. Боковая панель со статистикой
- [ ] **Панель статистики (правая/левая сторона)**
  - Текущий рейтинг в режиме "На рейтинг"
  - Серия правильных решений (streak)
  - Общая статистика за сессию
  - Процент правильных решений
  - Время, потраченное на задачу
  - История последних задач

- [ ] **Карточка режима**
  - Отображение текущего режима
  - Кнопка смены режима
  - Статистика по режиму

### 1.3. Улучшенная доска
- [ ] **Контролы доски**
  - Кнопка поворота доски (flip board)
  - Регулировка размера доски (+/-)
  - Кнопка "Начать сначала" (reset puzzle)
  - Кнопка "Показать решение" (для режима выживания)

- [ ] **Визуальные улучшения**
  - Плавные анимации ходов
  - Подсветка последнего хода
  - Анимация при правильном/неправильном ходе
  - Эффекты при решении задачи

## 📊 2. СТАТИСТИКА И ПРОГРЕСС

### 2.1. Статистика в реальном времени
- [ ] **Панель статистики**
  - Текущий рейтинг (для режима "На рейтинг")
  - Серия правильных решений (streak counter)
  - Всего решено сегодня/за сессию
  - Процент успешных решений
  - Среднее время решения

- [ ] **Графики и визуализация**
  - Мини-график изменения рейтинга
  - Прогресс-бар до следующего уровня рейтинга
  - История последних 10 задач

### 2.2. Достижения и мотивация
- [ ] **Система достижений**
  - Бейджи за серии (5, 10, 20 правильных подряд)
  - Достижения за рейтинг
  - Уведомления о достижениях

- [ ] **Мотивационные элементы**
  - Сообщения при достижении новых рекордов
  - Прогресс до следующего уровня
  - Сравнение с предыдущими результатами

## 🎮 3. ФУНКЦИОНАЛЬНОСТЬ

### 3.1. Управление задачей
- [ ] **Кнопки управления**
  - "Начать сначала" - сброс задачи
  - "Показать решение" - показать правильные ходы (только для выживания)
  - "Следующая задача" - пропустить текущую
  - "Отменить ход" - откатить последний ход (опционально)

- [ ] **История ходов**
  - Панель с историей ходов задачи
  - Возможность просмотра позиции на любом ходе
  - Навигация по ходам (предыдущий/следующий)
  - Отображение правильных ходов после решения

### 3.2. Информация о задаче
- [ ] **Дополнительная информация**
  - Тема задачи (mate, tactic, etc.)
  - Теги дебюта (если есть)
  - Популярность задачи
  - Количество решений другими игроками

- [ ] **Подсказки**
  - Кнопка "Подсказка" (показать первый ход)
  - Визуальные подсказки на доске
  - Текстовые подсказки по теме

### 3.3. Режимы работы
- [ ] **Улучшение режима "Выживание"**
  - Счетчик серии (streak)
  - Лучшая серия за сессию
  - Визуализация прогресса серии

- [ ] **Улучшение режима "На рейтинг"**
  - Отображение изменения рейтинга после решения
  - Прогресс до следующего уровня
  - История изменения рейтинга
