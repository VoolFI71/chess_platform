# 📱 План улучшения мобильной адаптации страницы Games

## 🔍 Анализ текущего состояния

### ✅ Что уже есть:
- Базовые медиа-запросы для 768px, 480px, 375px
- Адаптация для tabs, cards, modes-grid
- Адаптация для модальных окон
- Адаптация для waiting-room и TV games

### ❌ Проблемы:
1. **Нет fluid typography** - используются фиксированные размеры
2. **Нет адаптации для очень маленьких экранов** (360px, 320px)
3. **Нет оптимизации для landscape ориентации**
4. **Inline стили в HTML** - h1 использует inline стили вместо CSS классов
5. **Touch-цели не оптимизированы** - некоторые кнопки могут быть < 48px
6. **Tabs могут переполняться** на маленьких экранах
7. **Section titles** не адаптируются
8. **Modes grid** может быть слишком плотным на маленьких экранах
9. **Waiting items и TV games** могут быть неудобными на мобильных
10. **Модальные окна** могут быть слишком большими

---

## 📋 План улучшений

### **Фаза 1: Типографика и базовые элементы (30 мин)**

#### 1.1 Fluid Typography
- [ ] Заменить фиксированные размеры на `clamp()` для:
  - `.main-content h1` (2rem → clamp(1.5rem, 4vw, 2rem))
  - `.section-title` (1.5rem → clamp(1.25rem, 3vw, 1.5rem))
  - `.mode-time` (2rem → clamp(1.5rem, 3vw, 2rem))
  - `.mode-label` (0.875rem → clamp(0.75rem, 1.5vw, 0.875rem))
  - `.card-title` (1.125rem → clamp(1rem, 2vw, 1.125rem))

#### 1.2 Убрать inline стили
- [ ] Вынести inline стили из HTML в CSS классы
- [ ] Создать классы для заголовков и описаний

#### 1.3 Оптимизация tabs
- [ ] Улучшить адаптацию tabs для маленьких экранов
- [ ] Добавить scroll для tabs если нужно
- [ ] Компактные tabs на мобильных
