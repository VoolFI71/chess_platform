1. Общие положения

Настоящая Политика конфиденциальности (далее — «Политика») определяет порядок сбора, хранения и использования персональных данных пользователей платформы ChessMint (далее — «Платформа», «Сервис»).

Настоящая Политика разработана в соответствии с Федеральным законом от 27.07.2006 № 152-ФЗ «О персональных данных» и другими применимыми нормативными актами Российской Федерации.

Используя Платформу, вы соглашаетесь с условиями обработки персональных данных, изложенными в настоящей Политике.

2. Собираемые данные

2.1. Данные, предоставляемые пользователем

При регистрации и использовании Платформы мы собираем следующие данные:

  • Email адрес — для идентификации аккаунта и связи с пользователем
  • Имя пользователя (username) — для отображения на Платформе
  • Пароль — хранится в зашифрованном виде (хеш)
  • Рейтинги — рейтинги по различным форматам игры (blitz, bullet, rapid, puzzle)
  • Статистика игр — количество сыгранных партий, результаты
  • История партий — запись всех сыгранных партий
  • Статистика решения задач — количество решенных задач, результаты
  • Список друзей/подписок — связи между пользователями

2.2. Данные, собираемые автоматически

При использовании Платформы автоматически собираются:

  • IP адрес — для обеспечения безопасности и предотвращения злоупотреблений
  • User-Agent — информация о браузере и устройстве
  • Данные аналитики — через сервис Yandex.Metrika (анонимная статистика посещений, поведение пользователей, технические данные)
  • Session ID — для анонимных пользователей (хранится в localStorage браузера)
  • Предпочтения темы — светлая/темная тема (хранится в localStorage)

3. Цели обработки персональных данных

Персональные данные обрабатываются в следующих целях:

  • Предоставление услуг — обеспечение функционала Платформы (игры, задачи, курсы)
  • Идентификация пользователя — авторизация и управление аккаунтом
  • Расчет рейтингов — определение силы игры и рейтинга пользователя
  • Отображение статистики — показ истории игр, достижений, рейтингов
  • Улучшение сервиса — анализ использования Платформы для улучшения функционала
  • Безопасность — предотвращение мошенничества, злоупотреблений и нарушений правил
  • Коммуникация — связь с пользователем по вопросам использования Платформы
  • Аналитика — сбор анонимной статистики для улучшения работы Платформы

4. Способы обработки персональных данных

4.1. Хранение данных

Персональные данные хранятся в базе данных PostgreSQL на серверах, расположенных на территории Российской Федерации. Доступ к данным имеет ограниченный круг лиц, необходимый для обеспечения работы Платформы.

4.2. Использование cookies и localStorage

Платформа использует технологию localStorage браузера для хранения:

  • Токенов авторизации (access_token, refresh_token)
  • Предпочтений темы (темная/светлая)
  • Session ID для анонимных пользователей

Cookies используются опосредованно через сервис Yandex.Metrika для сбора аналитических данных.

5. Передача данных третьим лицам

5.1. Yandex.Metrika

Платформа использует сервис Yandex.Metrika для сбора анонимной аналитики. Данные передаются в анонимизированном виде и не позволяют идентифицировать конкретного пользователя. Подробнее о политике конфиденциальности Yandex.Metrika: https://yandex.ru/legal/confidential/

5.2. Облачные сервисы

Данные могут храниться на серверах облачных провайдеров, предоставляющих услуги хостинга. Все такие провайдеры обязаны соблюдать требования законодательства о защите персональных данных.

5.3. Требования законодательства

Администрация Платформы может раскрыть персональные данные в случаях, предусмотренных законодательством Российской Федерации, по запросам уполномоченных государственных органов.

6. Безопасность данных

6.1. Меры защиты

Администрация Платформы принимает необходимые технические и организационные меры для защиты персональных данных от неправомерного доступа, уничтожения, изменения или раскрытия:

  • Использование современных протоколов шифрования (HTTPS)
  • Хеширование паролей с использованием стойких алгоритмов
  • Ограничение доступа к персональным данным
  • Регулярное резервное копирование данных
  • Мониторинг и логирование доступа к данным

6.2. Ответственность пользователя

Пользователь несет ответственность за сохранение конфиденциальности данных для входа в аккаунт. При обнаружении несанкционированного доступа необходимо немедленно изменить пароль и уведомить администрацию Платформы.

7. Права пользователя

В соответствии с законодательством Российской Федерации, пользователь имеет следующие права:

  • Право на доступ — получение информации о своих персональных данных
  • Право на исправление — внесение изменений в некорректные данные
  • Право на удаление — удаление персональных данных (с возможным сохранением анонимизированной статистики)
  • Право на отзыв согласия — прекращение обработки персональных данных
  • Право на ограничение обработки — в случаях, предусмотренных законом
  • Право на возражение — против обработки данных в определенных случаях

Для реализации своих прав пользователь может обратиться к администрации Платформы по адресу support@chessmint.ru.

8. Хранение данных

8.1. Сроки хранения

Персональные данные хранятся в течение всего срока использования Платформы пользователем и в течение 3 (трех) лет после удаления аккаунта, если иное не предусмотрено законодательством.

8.2. Удаление данных

При удалении аккаунта пользователя удаляется следующая информация:

  • Email адрес
  • Имя пользователя
  • Пароль (хеш)
  • Личная статистика (по запросу)

Статистика и рейтинги могут быть сохранены в анонимизированном виде для ведения общих статистических данных Платформы.

8.3. Архивное хранение

В соответствии с требованиями законодательства некоторые данные могут храниться в архиве в течение установленных законом сроков.

9. Cookies и отслеживание

9.1. Использование cookies

Платформа использует cookies опосредованно через сервис Yandex.Metrika для сбора аналитики. Cookies — это небольшие текстовые файлы, которые сохраняются на устройстве пользователя.

9.2. Yandex.Metrika

Платформа использует Yandex.Metrika для сбора анонимной статистики о посещениях и использовании Платформы. Собираемые данные включают:

  • Количество посещений и просмотров страниц
  • Время, проведенное на страницах
  • Источники трафика
  • Технические данные (браузер, устройство, разрешение экрана)
  • Географические данные (страна, регион — без привязки к конкретному пользователю)

Данные собираются в анонимном виде и не позволяют идентифицировать конкретного пользователя.

9.3. Отключение отслеживания

Пользователь может отключить cookies и отслеживание в настройках своего браузера. Однако это может повлиять на функциональность Платформы.

10. Изменения в политике

Администрация Платформы оставляет за собой право вносить изменения в настоящую Политику конфиденциальности. Все изменения вступают в силу с момента их публикации на Платформе.

При существенных изменениях пользователи будут уведомлены путем размещения уведомления на Платформе или отправки уведомления на указанный email адрес.

Рекомендуется периодически просматривать настоящую Политику для ознакомления с актуальной информацией о защите персональных данных.

11. Контакты

По всем вопросам, связанным с обработкой персональных данных и реализацией прав пользователя, вы можете обращаться:

  • Email: support@chessmint.ru
  • Платформа: chessmint.ru

Администрация Платформы обязуется рассмотреть обращение в течение 30 календарных дней с момента его получения.

В случае несогласия с условиями обработки персональных данных пользователь имеет право прекратить использование Платформы и удалить свой аккаунт.
