# План улучшений страницы Tasks

## 📋 Обзор
План улучшений страницы выбора режима решения шахматных задач для повышения UX, визуальной привлекательности и конверсии.

---

## 🎨 Фаза 1: Визуальные улучшения (4-6 часов)

### 1.1 Улучшение карточек режимов
**Приоритет: Высокий**

- [ ] **Градиентные акценты**
  - Добавить тонкие градиентные обводки при hover
  - Градиентные тени для глубины
  - Анимированные градиенты для активной карточки

- [ ] **Микроанимации**
  - Плавное появление карточек при загрузке (stagger animation)
  - Hover эффекты с легким подъемом и масштабированием
  - Пульсирующая анимация для иконок (особенно для "Выживание")
  - Анимация при выборе режима (ripple effect)

- [ ] **Визуальная иерархия**
  - Увеличить размер иконок (особенно для лучшей видимости)
  - Улучшить контрастность текста
  - Добавить визуальные разделители между секциями карточки

### 1.2 Улучшение типографики
**Приоритет: Средний**

- [ ] **Заголовок и подзаголовок**
  - Добавить градиентный текст для ключевых слов в заголовке
  - Улучшить spacing между элементами
  - Добавить декоративные элементы (шахматные фигуры как акценты)

- [ ] **Карточки**
  - Улучшить читаемость описаний
  - Добавить визуальные акценты для важной информации (статистика)

### 1.3 Фоновые элементы
**Приоритет: Низкий**

- [ ] **Декоративные элементы**
  - Добавить плавающие шахматные фигуры на фоне (как на главной)
  - Градиентные пятна для глубины
  - Анимированные паттерны (subtle)

## 🚀 Фаза 2: Интерактивность и UX (5-7 часов)

### 2.1 Улучшение карточек режимов
**Приоритет: Высокий**

- [ ] **Интерактивные элементы**
  - Добавить кнопку "Начать" внутри каждой карточки (вместо клика по всей карточке)
  - Прогресс-бар для визуализации прогресса пользователя
  - Индикатор "Рекомендуется" для новых пользователей

- [ ] **Статистика и достижения**
  - Визуализация прогресса (progress rings)
  - Бейджи достижений (если есть)
  - Сравнение с предыдущими результатами

- [ ] **Подсказки и тултипы**
  - Информационные иконки с подсказками
  - Tooltip при hover на статистику
  - Объяснение различий между режимами

### 2.2 Onboarding для новых пользователей
**Приоритет: Средний**

- [ ] **Первое посещение**
  - Модальное окно с объяснением режимов
  - Highlight первого режима с подсказкой
  - Пошаговый гайд (опционально)

- [ ] **Визуальные подсказки**
  - Анимированные стрелки указывающие на карточки
  - Пульсирующие элементы для привлечения внимания
  - "Попробуйте оба режима" сообщение

### 2.3 Обратная связь
**Приоритет: Высокий**

- [ ] **Визуальная обратная связь**
  - Анимация выбора режима (checkmark, confetti)
  - Плавный переход к доске с задачей
  - Loading состояния с прогрессом

## ✅ Критерии успеха

1. **Визуальная привлекательность**: Карточки выглядят современно и привлекательно
2. **UX**: Пользователи легко понимают разницу между режимами
3. **Конверсия**: Увеличивается количество выбранных режимов
4. **Производительность**: Страница загружается быстро, анимации плавные
5. **Accessibility**: Страница доступна для всех пользователей
6. **Мобильная версия**: Отличный опыт на всех устройствах
