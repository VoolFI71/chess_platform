# Open Graph изображения для ChessMint

## 📋 Требования к изображениям

### Размеры:
- **Open Graph:** 1200x630px (соотношение 1.91:1)
- **Twitter Card:** 1200x600px (соотношение 2:1) - можно использовать то же изображение
- **Минимальный размер:** 600x315px
- **Максимальный размер файла:** 8MB (рекомендуется < 200KB для быстрой загрузки)

### Формат:
- PNG или JPG (оптимизированный)
- Рекомендуется: JPG для фотографий, PNG для графики с прозрачностью

### Оптимизация:
- Использовать инструменты сжатия (TinyPNG, ImageOptim, Squoosh)
- Цель: размер файла < 200KB при сохранении качества

## 🎨 Рекомендации по дизайну

### Цветовая схема:
- Основные цвета: Темные оттенки (#1e293b) + акценты
- Шахматная доска: Классические черно-белые клетки
- Логотип: Градиентный текст ChessMint

### Типографика:
- Заголовки: Жирный шрифт, легко читаемый
- Размер текста: Минимум 40px для читаемости в превью

### Композиция:
- Центральный элемент: Шахматная доска или интерфейс
- Логотип: В углу (верхний левый или правый)
- Текст: Внизу или по центру, контрастный фон

## 🔗 Использование в HTML

После создания изображений, обновить meta-теги на соответствующих страницах:

```html
<meta property="og:image" content="https://chessmint.ru/images/og/index.png">
<meta property="og:image:width" content="1200">
<meta property="og:image:height" content="630">
<meta property="og:image:alt" content="ChessMint - Шахматы онлайн бесплатно">
```
