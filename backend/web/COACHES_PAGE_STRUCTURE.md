# Структура страниц тренеров

## 🎯 Разделение контента

### `/coaches` - Общая страница о тренерстве
**Содержит:**
- Hero секция "Обучение шахматам с профессиональными тренерами"
- Секция "Чему учим" (польза шахмат)
- Секция "Почему онлайн?"
- **Список всех тренеров** (карточки с краткой информацией)
- Секция "Как проходят занятия" (общее описание процесса)
- Секция "Цены" (общие/стандартные цены)
- Секция "Для кого подходит" (уровни подготовки)
- Общие отзывы о тренерстве
- Достижения школы
- FAQ по обучению
- Форма записи (общая)

**Цель:** Информационная страница о услуге тренерства, SEO-оптимизация, конверсия.

---

### `/coach` или `/coach/{id}` - Страница конкретного тренера
**Содержит:**
- Hero с фото и основными данными тренера
- Подробная информация о тренере (биография, методология)
- Достижения конкретного тренера
- Отзывы конкретно об этом тренере
- Персональные цены (если отличаются от общих)
- Контакты тренера (Telegram)
- Форма записи к этому тренеру

**Цель:** Детальная информация о конкретном тренере, конверсия к записи.

---

## 🔗 Структура URL (рекомендуемая)

### Вариант 1: Текущая структура (простой)
```
/coaches          → coaches.html (список + информация о тренерстве)
/coach            → coach.html (страница Григория Пономарева)
```

**Плюсы:** Просто, один тренер сейчас  
**Минусы:** Не масштабируется для нескольких тренеров

---

### Вариант 2: Масштабируемая структура (рекомендуется)
```
/coaches          → coaches.html (список + информация о тренерстве)
/coach/grisha     → coach.html?coach=grisha или отдельный файл
/coach/{id}       → coach.html?coach={id} (динамическая загрузка данных)
```

**Плюсы:** Легко добавить новых тренеров  
**Минусы:** Нужна динамическая загрузка или отдельные файлы

---

### Вариант 3: Гибридный (для текущей ситуации)
```
/coaches          → coaches.html (список + информация о тренерстве)
/coach            → coach.html (Григорий Пономарев - текущая страница)
```

**Когда появятся другие тренеры:**
- Переделать `/coach` → `/coach/grisha`
- Добавить `/coach/{id}` для других тренеров

---

## 📋 Рекомендация

**Для текущего момента (1 тренер):**
```
/coaches  → Общая страница о тренерстве (НОВАЯ страница)
/coach    → Страница Григория Пономарева (СУЩЕСТВУЮЩАЯ)
```

**В будущем (когда будет больше тренеров):**
```
/coaches       → Общая страница со списком всех тренеров
/coach/grisha  → Страница Григория Пономарева (переименовать текущую)
/coach/ivan    → Страница другого тренера
```

## 🔄 Навигация между страницами

### С `/coaches`:
- Карточка тренера → кнопка "Подробнее" → `/coach` (или `/coach/grisha`)
- Карточка тренера → кнопка "Записаться" → форма записи (модальное окно)

### С `/coach`:
- Хлебные крошки: Главная / Тренеры / [Имя тренера]
- Кнопка "Все тренеры" → `/coaches`
- CTA "Записаться" → форма записи к этому тренеру

### С главной страницы:
- Секция "Тренеры" → ссылка "Все тренеры" → `/coaches`
- Карточка тренера → "Подробнее" → `/coach`
