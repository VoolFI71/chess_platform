# Руководство по SEO для PowerChess

## Что было добавлено

### 1. Meta теги
- ✅ Title теги с ключевыми словами для каждой страницы
- ✅ Description теги с описанием контента
- ✅ Keywords теги для основных страниц
- ✅ Robots meta теги (index/noindex)
- ✅ Canonical URLs для предотвращения дублирования контента

### 2. Open Graph теги
- ✅ og:type, og:url, og:title, og:description
- ✅ og:image для социальных сетей
- ✅ og:locale и og:site_name

### 3. Twitter Card
- ✅ twitter:card, twitter:title, twitter:description
- ✅ twitter:image для красивого отображения в Twitter

### 4. Структурированные данные (JSON-LD)
- ✅ Schema.org разметка для главной страницы (EducationalOrganization)
- ✅ Schema.org для страницы игр (WebApplication)
- ✅ Schema.org для страницы курсов (Course)

### 5. Технические файлы
- ✅ robots.txt - указания для поисковых роботов
- ✅ sitemap.xml - карта сайта для индексации

## Что нужно сделать дополнительно

### 1. Создать изображение для Open Graph
Создайте файл `og-image.jpg` размером 1200x630px и разместите его в `/backend/web/`
Изображение должно содержать:
- Логотип PowerChess
- Краткое описание платформы
- Привлекательный дизайн для социальных сетей

### 2. Обновить sitemap.xml
Когда сайт будет на продакшене:
- Обновите дату `lastmod` на текущую
- Добавьте реальный домен вместо `powerchess.org`
- Настройте автоматическое обновление sitemap при добавлении новых страниц

### 3. Настроить Google Search Console
1. Зарегистрируйтесь в [Google Search Console](https://search.google.com/search-console)
2. Добавьте свой сайт
3. Подтвердите владение сайтом
4. Отправьте sitemap.xml

### 4. Настроить Яндекс.Вебмастер
1. Зарегистрируйтесь в [Яндекс.Вебмастер](https://webmaster.yandex.ru)
2. Добавьте свой сайт
3. Подтвердите владение
4. Отправьте sitemap.xml

### 5. Добавить alt теги к изображениям
Убедитесь, что все изображения на сайте имеют атрибут `alt` с описательным текстом.

### 6. Оптимизировать заголовки
Проверьте, что на каждой странице есть:
- Один H1 заголовок с основным ключевым словом
- H2-H6 заголовки для структурирования контента

### 7. Внутренняя перелинковка
Добавьте ссылки между страницами для улучшения индексации:
- С главной страницы на основные разделы
- Между связанными страницами (курсы → тренеры)

### 8. Скорость загрузки
- Оптимизируйте изображения (WebP формат, сжатие)
- Минифицируйте CSS и JavaScript
- Используйте CDN для статических ресурсов

### 9. Мобильная оптимизация
- Убедитесь, что сайт полностью адаптивен (уже есть)
- Проверьте через [Google Mobile-Friendly Test](https://search.google.com/test/mobile-friendly)

### 10. HTTPS
Убедитесь, что сайт работает по HTTPS (обязательно для хорошего SEO)

## Проверка SEO

### Инструменты для проверки:
1. [Google PageSpeed Insights](https://pagespeed.web.dev/) - скорость загрузки
2. [Google Rich Results Test](https://search.google.com/test/rich-results) - структурированные данные
3. [Schema Markup Validator](https://validator.schema.org/) - валидация JSON-LD
4. [Screaming Frog SEO Spider](https://www.screamingfrog.co.uk/seo-spider/) - полный аудит

## Рекомендации по контенту

1. **Регулярно обновляйте контент** - поисковики любят свежий контент
2. **Добавьте блог** - статьи о шахматах помогут привлечь органический трафик
3. **Создайте страницы для каждого курса** - отдельные страницы с описанием курсов
4. **Добавьте FAQ раздел** - ответы на частые вопросы улучшат SEO

## Мониторинг

После запуска отслеживайте:
- Позиции в поисковой выдаче
- Органический трафик
- Индексацию страниц
- Ошибки в Search Console
