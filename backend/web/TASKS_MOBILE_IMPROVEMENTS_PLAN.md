# 📱 План улучшения мобильной адаптации страницы Tasks

## 🔍 Анализ текущего состояния

### ✅ Что уже есть:
- Базовые медиа-запросы для 768px, 1024px, 480px
- Layout переходит в одну колонку на мобильных (1024px)
- Адаптация карточек режимов
- Базовые стили для sidebar

### ❌ Проблемы:
1. **Нет адаптации для очень маленьких экранов** (360px, 320px)
2. **Нет оптимизации для landscape ориентации**
3. **Шахматная доска** может быть слишком большой/маленькой
4. **Sidebar карточки** занимают много места
5. **Breadcrumbs** могут переполняться
6. **Header** занимает много вертикального пространства
7. **Touch-цели** не оптимизированы (кнопки < 48px)
8. **Typography** не использует fluid (clamp)
9. **Padding/margin** слишком большие на маленьких экранах
10. **Мета-информация** (pills) может переполняться

---

## 📋 План улучшений

### **Фаза 1: Типографика и базовые элементы (30 мин)**

#### 1.1 Fluid Typography
- [ ] Заменить фиксированные размеры на `clamp()` для:
  - `.tasks-title` (3rem → clamp(1.75rem, 4vw, 3rem))
  - `.tasks-subtitle` (1.25rem → clamp(0.95rem, 2vw, 1.25rem))
  - `.mode-name` (2rem → clamp(1.5rem, 3vw, 2rem))
  - `.mode-description` (1rem → clamp(0.875rem, 1.5vw, 1rem))
  - `.sidebar-title` (1.25rem → clamp(1rem, 2vw, 1.25rem))

#### 1.2 Breadcrumbs адаптация
- [ ] Скрыть breadcrumbs на экранах < 480px
- [ ] Или сделать более компактными (меньший шрифт, меньше padding)

#### 1.3 Header оптимизация
- [ ] Уменьшить padding header на мобильных
- [ ] Компактный логотип на маленьких экранах

---

### **Фаза 2: Карточки режимов (20 мин)**

#### 2.1 Адаптация для маленьких экранов
- [ ] Уменьшить padding на 360px, 320px
- [ ] Уменьшить размер иконок
- [ ] Оптимизировать min-height
- [ ] Улучшить spacing между элементами

#### 2.2 Touch-цели
- [ ] Убедиться, что `.mode-card` имеет min-height 48px для touch
- [ ] Увеличить padding для лучшего touch-опыта

---

### **Фаза 3: Layout задачи (puzzle-section) (45 мин)**

#### 3.1 Шахматная доска
- [ ] Адаптивный размер доски:
  - 768px: max-width 100%
  - 480px: max-width calc(100vw - 2rem)
  - 360px: max-width calc(100vw - 1rem)
  - 320px: max-width calc(100vw - 0.5rem)
- [ ] Оптимизация для landscape:
  - Уменьшить доску при landscape + низкая высота
  - Скрыть/свернуть sidebar

#### 3.2 Sidebar карточки
- [ ] Компактный режим для мобильных:
  - Уменьшить padding
  - Меньшие иконки
  - Более компактная типографика
  - Скрыть менее важную информацию
- [ ] Collapsible sidebar (опционально):
  - Кнопка для сворачивания/разворачивания
  - Сохранять состояние в localStorage

#### 3.3 Puzzle meta pills
- [ ] Адаптивный layout:
  - На маленьких экранах: вертикальный стек
  - Уменьшить font-size
  - Уменьшить padding
  - Перенос текста

#### 3.4 История ходов
- [ ] Ограничить высоту на мобильных
- [ ] Добавить scroll
- [ ] Компактные кнопки навигации
