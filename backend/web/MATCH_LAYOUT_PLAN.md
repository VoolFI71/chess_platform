### Особенности мобильной версии:

#### 1. Игроки (компактные панели):
- **Высота**: ~60-70px (меньше, чем на desktop)
- **Ширина**: 100% экрана
- **Расположение**: Сверху и снизу от доски
- **Содержимое**: Имя игрока + таймер в одну строку
- **Отступы**: Минимальные (0.5rem сверху/снизу)

#### 2. Доска:
- **Ширина**: 100% ширины экрана (на всю ширину телефона)
- **Размер**: Адаптивный, квадратная (aspect-ratio: 1)
- **Отступы**: Минимальные (0.25rem - 0.5rem по бокам, только для визуального отступа)
- **Максимальная ширина**: Не ограничена (использует всю доступную ширину экрана)
- **Важно**: На мобильных доска должна занимать практически всю ширину экрана

#### 3. Статус партии:
- **Высота**: Автоматическая (компактная)
- **Ширина**: 100%
- **Отступы**: 1rem сверху/снизу
- **Содержимое**: Вертикальный список (каждая строка на новой строке)

#### 4. Список ходов:
- **Высота**: Ограничена (~250-300px) с прокруткой
- **Ширина**: 100%
- **Отступы**: 1rem сверху/снизу
- **Навигация**: Кнопки компактные, иконки без текста

#### 5. Действия:
- **Высота**: Автоматическая
- **Ширина**: 100%
- **Кнопки**: На полную ширину, вертикальный стек
- **Отступы**: 1rem сверху/снизу, 0.75rem между кнопками

## Детали позиционирования

### Игроки:
- **Расположение**: Внутри `board-column`, сверху и снизу от доски
- **Ширина**: Соответствует ширине доски (max-width: 800px)
- **Отступы**: Небольшой gap между игроком и доской (1rem)
- **Выравнивание**: По центру относительно доски

### Доска:
- **Расположение**: В центре `board-column`
- **Ширина**: 100% от родителя, max-width: 800px
- **Выравнивание**: Центрирована по горизонтали
- **Отступы**: Игроки сверху и снизу

### Левая панель (Статус + Действия):
- **Ширина**: Фиксированная 280px на desktop
- **Позиционирование**: Sticky (прилипает при скролле)
- **Выравнивание**: Сверху, на уровне начала доски
- **Вертикальный стек**: Статус сверху, действия снизу

### Правая панель (Ходы):
- **Ширина**: Фиксированная 320px на desktop
- **Позиционирование**: Sticky (прилипает при скролле)
- **Выравнивание**: Сверху, на уровне начала доски
- **Высота**: Ограничена высотой viewport с отступом

## Изменения в существующих стилях

### 1. `.match-grid` → `.match-center-wrapper`
- Заменить grid-template-columns
- Изменить структуру с 2 колонок на 3

### 2. `.match-left` → `.board-column`
- Убрать, заменить на `.board-column`
- Добавить flex-direction: column
- Центрировать содержимое

### 3. `.match-right` → удалить
- Разделить на `.sidebar-left` и `.sidebar-right`
- Игроки переместить в `.board-column`

### 4. `.player-stack` → `.player-section`
- Убрать обертку `.player-stack`
- Игроки напрямую в `.board-column`
- Добавить классы `.player-top` и `.player-bottom`

### 5. Боковые панели
- Добавить `.sidebar-left` и `.sidebar-right`
- Sticky positioning для desktop
- Фиксированная ширина на desktop
