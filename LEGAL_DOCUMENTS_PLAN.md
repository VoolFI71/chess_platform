# 📋 План создания юридических документов для ChessMint

## 🎯 ЦЕЛЬ

Создать пользовательское соглашение и политику конфиденциальности для платформы ChessMint в соответствии с требованиями российского законодательства (152-ФЗ "О персональных данных", ГК РФ).

---

## 📊 АНАЛИЗ ТЕКУЩЕГО СОСТОЯНИЯ

### Существующая структура:

1. **Футер сайта:**
   - Есть ссылки на "#privacy" (Конфиденциальность) и "#terms" (Условия)
   - Но это якоря (#), а не реальные страницы
   - Находится в разделе "Поддержка" → "Конфиденциальность" и "Условия"

2. **Собираемые данные (найдено):**
   - **При регистрации:**
     - Email
     - Username
     - Password (хешированный)
   
   - **При использовании:**
     - Рейтинги (blitz, bullet, rapid, puzzle)
     - Статистика игр (games_played)
     - История партий
     - Статистика решенных задач
     - Друзья/подписки
     - Предпочтение темы (dark/light) - localStorage
     - Session ID для анонимных пользователей - localStorage
   
   - **Технические данные:**
     - Yandex.Metrika (аналитика, webvisor, clickmap)
     - IP адреса (логи сервера)
     - User-Agent (браузер, устройство)

3. **Хранение данных:**
   - PostgreSQL база данных
   - localStorage браузера (тема, токены, session_id)
   - Cookies (опосредованно через Yandex.Metrika)

## 📝 ПЛАН ДЕЙСТВИЙ

### Этап 1: Создание HTML страниц (1-2 часа)

#### 1.1. Создать страницу `/terms.html`
**Расположение:** `backend/web/terms.html`

**Структура:**
- Заголовок с названием "Пользовательское соглашение"
- Дата последнего обновления
- Основной контент (все разделы)
- Ссылка на политику конфиденциальности
- Стилизация (использовать существующие стили)

#### 1.2. Создать страницу `/privacy.html`
**Расположение:** `backend/web/privacy.html`

**Структура:**
- Заголовок с названием "Политика конфиденциальности"
- Дата последнего обновления
- Основной контент (все разделы)
- Ссылка на пользовательское соглашение
- Стилизация (использовать существующие стили)

#### 1.3. Стилизация страниц
**Расположение:** `backend/web/styles/pages/legal.css` (новый файл)

**Требования:**
- Адаптивный дизайн (mobile-first)
- Темная/светлая тема
- Читаемость (хорошая типографика)
- Навигация (якоря для разделов)

### Этап 2: Написание текстов документов (3-4 часа)

#### 2.1. Пользовательское соглашение

**Структура документа:**

1. **Преамбула**
   - Определение платформы
   - Правовые основания
   - Принятие условий

2. **Термины и определения**
   - Платформа, Пользователь, Контент
   - Услуги, Сервис

3. **Регистрация и аккаунт**
   - Требования к возрасту (18+ или 14+ с согласием родителей)
   - Ответственность за безопасность аккаунта
   - Один аккаунт на пользователя

4. **Использование платформы**
   - Разрешенное использование
   - Запрещенные действия (читерство, оскорбления, спам)
   - Правила поведения

5. **Интеллектуальная собственность**
   - Права на контент платформы
   - Права пользователя на свой контент
   - Лицензия на использование

6. **Рейтинги и статистика**
   - Система рейтингов ELO
   - Прозрачность расчетов
   - Запрет манипуляций

7. **Платные услуги (если есть)**
   - Описание платных функций
   - Возврат средств
   - Отмена подписки

8. **Ответственность**
   - Ограничение ответственности
   - Исключения
   - Компенсация ущерба

9. **Прекращение доступа**
   - Условия блокировки
   - Процедура обжалования
   - Удаление данных

10. **Изменение соглашения**
    - Право на изменение
    - Уведомление пользователей
    - Вступление в силу

11. **Разрешение споров**
    - Применимое право (РФ)
    - Подсудность
    - Претензионный порядок

12. **Контакты**
    - Email для связи
    - Адрес (если есть юридическое лицо)

#### 2.2. Политика конфиденциальности

**Структура документа:**

1. **Общие положения**
   - Цель документа
   - Правовые основания (152-ФЗ)
   - Определение персональных данных

2. **Собираемые данные**
   - Данные, собираемые автоматически
   - Данные, предоставляемые пользователем
   - Данные от третьих сторон

3. **Цели обработки персональных данных**
   - Предоставление услуг
   - Улучшение сервиса
   - Аналитика и статистика
   - Безопасность

4. **Способы обработки**
   - Хранение в БД
   - Использование cookies/localStorage
   - Аналитические системы (Yandex.Metrika)

5. **Передача данных третьим лицам**
   - Yandex.Metrika (анонимная статистика)
   - Облачные сервисы (хостинг)
   - Требования законодательства

6. **Безопасность данных**
   - Меры защиты
   - Шифрование паролей
   - Ограничение доступа

7. **Права пользователя**
   - Право на доступ к данным
   - Право на исправление
   - Право на удаление
   - Право на отзыв согласия

8. **Хранение данных**
   - Сроки хранения
   - Удаление после прекращения использования
   - Архивное хранение

9. **Cookies и отслеживание**
   - Использование cookies
   - Yandex.Metrika
   - Настройка браузера

10. **Изменения в политике**
    - Уведомление об изменениях
    - Дата последнего обновления

11. **Контакты**
    - Ответственное лицо
    - Email для обращений
    - Сроки рассмотрения

### Этап 3: Обновление футера и ссылок (30 минут)

#### 3.1. Обновить ссылки в футере
**Файлы для обновления:**
- `backend/web/index.html`
- `backend/web/games.html`
- `backend/web/tasks.html`
- `backend/web/profile.html`
- `backend/web/course.html`
- `backend/web/leaderboard.html`
- `backend/web/match.html`
- `backend/web/login.html`
- `backend/web/register.html`
- `backend/web/reset-password.html`
- `backend/web/couch.html`

**Изменения:**
```html
<!-- Было: -->
<li><a href="#privacy">♟ Конфиденциальность</a></li>
<li><a href="#terms">♟ Условия</a></li>

<!-- Станет: -->
<li><a href="/privacy">♟ Конфиденциальность</a></li>
<li><a href="/terms">♟ Пользовательское соглашение</a></li>
```

#### 3.2. Добавить ссылки в регистрацию/вход
**Опционально:** Добавить чекбоксы с согласием при регистрации:
```html
<label>
  <input type="checkbox" required>
  Я согласен с <a href="/terms" target="_blank">Пользовательским соглашением</a>
  и <a href="/privacy" target="_blank">Политикой конфиденциальности</a>
</label>
```

---

### Этап 4: Интеграция с бэкендом (опционально, 1-2 часа)

#### 4.1. Роутинг в FastAPI
**Файл:** `backend/app/main.py`

Добавить статическую раздачу или роуты:
```python
@app.get("/terms")
async def terms():
    return FileResponse("web/terms.html")

@app.get("/privacy")
async def privacy():
    return FileResponse("web/privacy.html")
```

Или использовать существующий статический роутинг (если он уже есть).

#### 4.2. Добавить мета-теги для SEO
**Файлы:** `terms.html`, `privacy.html`

Добавить:
- `<meta name="robots" content="noindex, follow">` (не индексировать, но следовать ссылкам)
- Canonical URL
- Структурированные данные (Schema.org)

## ⚠️ ВАЖНЫЕ ЮРИДИЧЕСКИЕ МОМЕНТЫ

### Для пользовательского соглашения:

1. **Возрастные ограничения:**
   - Определить минимальный возраст (14+ или 18+)
   - Если 14+, добавить требование согласия родителей

2. **Запрещенные действия:**
   - Читерство в играх
   - Использование ботов
   - Оскорбления и харассмент
   - Спам и реклама
   - Нарушение авторских прав

3. **Рейтинги:**
   - Указать, что рейтинги могут быть скорректированы при обнаружении читерства
   - Право на удаление аккаунта с потерей рейтинга

4. **Ответственность:**
   - Ограничение ответственности за качество интернет-соединения
   - Невозможность гарантировать 100% uptime

### Для политики конфиденциальности:

1. **152-ФЗ требования:**
   - Определение оператора персональных данных
   - Цели обработки
   - Сроки хранения
   - Права субъекта персональных данных

2. **Yandex.Metrika:**
   - Указать, что используется аналитика
   - Ссылка на политику Yandex
   - Возможность отключения через настройки браузера

3. **Местонахождение серверов:**
   - Указать, где хранятся данные (РФ/зарубеж)
   - Трансграничная передача (если есть)

4. **Cookies:**
   - Объяснить, какие cookies используются
   - Как отключить
