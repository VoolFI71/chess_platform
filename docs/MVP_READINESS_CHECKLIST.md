## 🔴 КРИТИЧНЫЕ ПРОБЛЕМЫ (БЛОКЕРЫ)

### 1. **API фильтрация партий по статусу** ✅
- **Проблема:** `/api/games/?status=ACTIVE` не фильтрует по статусу, возвращает все игры
- **Файл:** `games_service_go/internal/handlers/games.go`
- **Влияние:** Лишний трафик, завершенные партии в TV режиме
- **Приоритет:** 🔴 **КРИТИЧЕСКИЙ**
- **Статус:** ✅ **ИСПРАВЛЕНО**
- **Решение:** 
  - Добавлена обработка параметра `status` в handler `listGames`
  - Добавлена валидация статуса (CREATED, ACTIVE, PAUSED, FINISHED)
  - Добавлена валидация `limit` (1-100) и `offset` (>=0)
  - Обновлен метод `ListGames` в service для фильтрации по статусу. 

### 2. **Удаление заброшенных партий** ✅
- **Проблема:** Заброшенные партии не удалялись из БД
- **Файл:** `games_service_go/internal/watchdog/watchdog.go`
- **Влияние:** Засорение БД и зала ожидания
- **Приоритет:** 🔴 **КРИТИЧЕСКИЙ**
- **Статус:** ✅ **ИСПРАВЛЕНО** (убрано условие `move_count = 0`, упрощена проверка metadata, таймаут 60 минут)
