## Выполненные изменения

### 1. Расширен `chess-move-utils.js`

Добавлены общие функции для всех модулей:

#### `pieceBelongsToPlayer(piece, playerColor)`
- Унифицированная проверка принадлежности фигуры игроку
- Поддерживает форматы: 'white'/'black' и 'w'/'b'
- Используется во всех трех модулях

#### `getPieceAtSquare(fen, square)`
- Получение фигуры на указанной клетке из FEN
- Использует существующий `squareToCoords()` для конвертации
- Возвращает `piece` или `null`

#### Экспортированы существующие функции:
- `squareToCoords()` - уже была, теперь экспортирована
- `squareToIndices()` - обертка над `squareToCoords()`
