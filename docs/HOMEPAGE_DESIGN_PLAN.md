**Основные цвета:**
```css
--primary: #3b82f6;      /* Синий - доверие, стабильность */
--secondary: #8b5cf6;    /* Фиолетовый - креатив */
--accent: #f59e0b;       /* Золотой - премиум */
--success: #10b981;      /* Зеленый - успех */
--danger: #ef4444;       /* Красный - ошибки */
--dark: #1e293b;         /* Темный фон */
```

**Градиенты:**
```css
/* Hero background */
background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
```

### Типографика

**Шрифты:**
- **Заголовки:** Inter, Montserrat (bold, 600-800 weight)
- **Текст:** Inter, Open Sans (regular, 400-500 weight)
- **Моноширинный:** Fira Code (для кода/нотации)

**Размеры:**
```css
h1: 3.5rem (56px) - Hero заголовок
h2: 2.5rem (40px) - Секции
h3: 1.5rem (24px) - Подзаголовки
p: 1rem (16px) - Основной текст
```

## Технические фишки

### 1. Lazy Loading

```javascript
// Загружаем секции по мере прокрутки
const observer = new IntersectionObserver((entries) => {
  entries.forEach(entry => {
    if (entry.isIntersecting) {
      entry.target.classList.add('visible');
    }
  });
});
```

### 2. Smooth Scroll

```css
html {
  scroll-behavior: smooth;
}

/* Якоря работают плавно */
<a href="#features">О платформе</a>
```

### 3. Loading State

```html
<!-- Skeleton пока загружается контент -->
<div class="skeleton-card"></div>
<div class="skeleton-text"></div>
```

### 4. Микроинтеракции

- ✨ Confetti при решении задачи
- 🎉 Success animation при мате
- 💫 Particles при hover на доску
- 🔥 Fire emoji анимация для streak
