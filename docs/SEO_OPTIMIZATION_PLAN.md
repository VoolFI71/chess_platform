## 🔴 КРИТИЧЕСКИЕ ПРОБЛЕМЫ (Высокий приоритет)

### 1. Страница Games (`games.html`)

#### Проблема: Отсутствует H1 заголовок
**Текущее состояние:** В HTML нет основного заголовка H1 на странице  
**Решение:**
- Добавить H1 в начале `<main>` контейнера
- Текст: "Играть в шахматы онлайн бесплатно"
- Разместить перед табами, сделать видимым для пользователей

**Пример реализации:**
```html
<main class="main-content">
    <div class="games-page-layout">
        <div class="container">
            <h1 class="games-main-title">Играть в шахматы онлайн бесплатно - Блиц, Рапид, Классика</h1>
            <!-- Остальной контент -->
```

---

#### Проблема: Недостаточно статического текстового контента
**Текущее состояние:** Весь контент загружается динамически через JavaScript  
**Решение:**
- Добавить статический блок с описанием режимов игры перед табами
- Включить ключевые слова: "блиц шахматы", "рапид шахматы", "классические шахматы онлайн"
- Добавить краткое описание каждого режима с указанием тайм-контроля

**Структура контента:**
```
1. Вводный абзац (2-3 предложения)
2. Секция "Режимы игры" с описанием:
   - Bullet (1+0) - Молниеносные партии
   - Blitz (3+0, 3+2, 5+0, 5+3) - Быстрые партии
   - Rapid (10+0, 10+5, 15+10) - Рапид партии
   - Classical (30+0) - Классические шахматы
3. Секция "Как играть" (краткая инструкция)
```

### 2. Страница Tasks (`tasks.html`)

#### Проблема: Отсутствует structured data для шахматных задач
**Текущее состояние:** Нет Schema.org разметки для задач  
**Решение:**
- Добавить `Game` или `Puzzle` schema с информацией о задачах
- Указать количество задач, режимы, рейтинги

**Пример structured data:**
```json
{
  "@context": "https://schema.org",
  "@type": "Game",
  "name": "Шахматные задачи онлайн",
  "description": "Более 1.000.000 шахматных задач для тренировки тактики",
  "gameItem": [
    {"@type": "Thing", "name": "Мат в 1 ход"},
    {"@type": "Thing", "name": "Мат в 2 хода"},
    {"@type": "Thing", "name": "Мат в 3 хода"},
    {"@type": "Thing", "name": "Тактические комбинации"}
  ]
}
```

---

#### Проблема: Недостаточно контекстных ключевых слов
**Текущее состояние:** В description мало терминов  
**Решение:**
- Расширить description с упоминанием типов задач
- Добавить статический текст о типах задач и режимах тренировки

**Новые ключевые слова для добавления:**
- "мат в 1 ход"
- "мат в 2 хода"

## 📝 ПРИМЕРЫ КОНТЕНТА

### Для страницы Games:

#### H1 заголовок:
```html
<h1 class="games-main-title">Играть в шахматы онлайн бесплатно - Блиц, Рапид, Классика</h1>
```

#### Вводный текст:
```
Играйте в шахматы онлайн на ChessMint бесплатно. Выберите режим игры: 
Bullet (1+0) для молниеносных партий, Blitz (3+0, 3+2, 5+0, 5+3) для быстрых 
партий, Rapid (10+0, 10+5, 15+10) для рапид партий или Classical (30+0) для 
классических шахмат. Создавайте партии с друзьями или играйте с соперниками 
со всего мира. Реальный рейтинг ELO, анализ партий, мобильная версия.
```

#### Описание режимов:
```
**Bullet (1+0)** - Молниеносные партии, где у каждого игрока всего 1 минута 
на всю партию. Идеально для быстрых тренировок и развития интуиции.

**Blitz (3+0, 3+2, 5+0, 5+3)** - Быстрые партии блиц. Классический формат 
онлайн шахмат. От 3 до 5 минут на партию с возможным добавлением времени 
после каждого хода.

**Rapid (10+0, 10+5, 15+10)** - Рапид партии для более вдумчивой игры. 
От 10 до 15 минут на партию. Позволяют лучше обдумать стратегию.

**Classical (30+0)** - Классические шахматы онлайн. 30 минут на партию для 
глубокого анализа позиций. Подходит для серьезных тренировок.
```

### Для страницы Tasks:

#### Расширенный description:
```
Решайте шахматные задачи онлайн на ChessMint бесплатно. Более 1.000.000 
тактических задач для тренировки: мат в 1 ход, мат в 2 хода, мат в 3 хода, 
тактические комбинации, дебютные задачи. Режимы: выживание, рейтинг, марафон. 
Улучшайте тактику, комбинации, стратегию. Задачи для начинающих, любителей 
и мастеров. Тренировка шахматной тактики онлайн.
```

#### Статический контент:
```
**Что такое шахматные задачи?**
Шахматные задачи - это позиции из реальных партий, где нужно найти 
правильный ход. Решая задачи, вы тренируете тактическое зрение, учитесь 
видеть комбинации и улучшаете общее понимание игры.

**Типы задач:**
- Мат в 1 ход - найдите матовую комбинацию за один ход
- Мат в 2 хода - найдите матовую комбинацию за два хода
- Мат в 3 хода - найдите матовую комбинацию за три хода
- Тактические комбинации - выиграйте материал или позицию
- Дебютные задачи - изучение типичных дебютных позиций

**Режимы тренировки:**
- Выживание - решайте задачи до первой ошибки
- Рейтинг - улучшайте свой рейтинг, решая задачи
- Марафон - решайте максимальное количество задач
```
