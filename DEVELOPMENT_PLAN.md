# План развития проекта PowerChess

## 📊 Текущее состояние проекта

### ✅ Реализовано

**Микросервисы:**
- ✅ Auth Service - аутентификация, регистрация, JWT токены
- ✅ Users Service - управление пользователями, друзья
- ✅ Games Service - создание игр, WebSocket для реального времени
- ✅ Puzzles Service - задачи, статистика, рейтинг
- ✅ Courses Service - курсы
- ✅ Lessons Service - уроки
- ✅ Enrollments Service - записи на курсы
- ✅ Payments Service - оплата курсов
- ✅ Notifications Service - уведомления

**Frontend:**
- ✅ Главная страница (index.html)
- ✅ Страница игр (games.html) с WebSocket
- ✅ Страница задач (tasks.html) с двумя режимами
- ✅ Страница профиля (profile.html)
- ✅ Страница курсов (course.html)
- ✅ Страница тренеров (couch.html) - статическая
- ✅ Страница лидеров (leaderboard.html) с рейтинговой таблицей
- ✅ Регистрация/Вход (register.html, login.html)

**Инфраструктура:**
- ✅ Docker Compose для оркестрации
- ✅ Nginx Gateway с SSL (Let's Encrypt)
- ✅ PostgreSQL база данных
- ✅ MinIO для хранения файлов
- ✅ Мониторинг: Prometheus, Grafana, Loki
- ✅ Миграции Alembic для всех сервисов

**Функциональность:**
- ✅ Система друзей:
  - UI для управления друзьями в профиле
  - Поиск пользователей для добавления в друзья
  - Приглашение друзей в игру
  - Список друзей и заявок в друзья
- ✅ Рейтинговая система:
  - Elo рейтинг для игр (blitz, rapid, bullet)
  - Elo рейтинг для задач (puzzle rating)
  - Рейтинговая история с фильтрацией по форматам
  - Рейтинговая таблица (leaderboard) с топ-50 игроков
  - Отображение рейтинга в профиле
  - Синхронизация рейтинга задач с таблицей users
- ✅ Улучшенный UI страницы лидеров с современным дизайном

#### 1. Сервис Турниров (Tournaments Service)
**Статус:** Упоминается в UI, но не реализован

**Задачи:**
- [ ] Создать `tournaments_service/` с базовой структурой
- [ ] Модели: Tournament, TournamentParticipant, TournamentMatch
- [ ] Типы турниров: Swiss, Round-Robin, Knockout
- [ ] API endpoints:
  - `GET /api/tournaments/` - список турниров
  - `POST /api/tournaments/` - создание турнира
  - `POST /api/tournaments/{id}/register` - регистрация
  - `GET /api/tournaments/{id}/standings` - таблица
  - `GET /api/tournaments/{id}/matches` - матчи
- [ ] Интеграция с Games Service для автоматических пар
- [ ] WebSocket для обновлений турнира в реальном времени
- [ ] Frontend: страница турниров (`tournaments.html`)

**Оценка:** 2-3 недели

**Статус:** Страница есть, но статическая
