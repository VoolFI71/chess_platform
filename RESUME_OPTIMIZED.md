    # Резюме (оптимизированная версия)

## Достижения

**Оптимизировал микросервис API случайной выборки шахматных задач:** реализовал in-memory кеш с паттерном stale-while-revalidate, оптимизировал запросы к PostgreSQL через TABLESAMPLE, внедрил GZip сжатие и быструю JSON сериализацию через orjson. Улучшил время ответа 99-го процентиля с 130ms до 8.5ms (ускорение в 15x), увеличил пропускную способность на 15%, достиг коэффициента сжатия 22%. Применил GZip сжатие во всех микросервисах проекта для снижения сетевого трафика на 20-30%.

**Внедрил схему хранения одноразовых кодов в Redis** с защитой от повторного использования и снижением задержек подтверждения. Сократил среднее время подтверждения с 250 ms до 90 ms.

**Перепроектировал REST‑сервис на асинхронную архитектуру** (FastAPI + uvicorn + async DB pool): уменьшил среднее время обработки с 150 ms до 90 ms, снизил p95 с 250 ms до 120 ms и повысил пропускную способность с 1.2k RPS до 3k RPS.
