# 🎯 Округление рейтинга для стабильности кеша

## ❌ Проблема

Когда пользователь решает задачи, его рейтинг постоянно меняется:
- 1331 → 1335 → 1342 → 1338 → 1345...

Каждое изменение создает **новый ключ кеша**:
```
Рейтинг 1331: rmin_1181|rmax_1481
Рейтинг 1335: rmin_1185|rmax_1485  ← Новый кеш!
Рейтинг 1342: rmin_1192|rmax_1492  ← Еще один новый кеш!
Рейтинг 1338: rmin_1188|rmax_1488  ← И еще один!
```

**Последствия:**
- Постоянное создание новых кешей
- Кеш не переиспользуется
- Больше нагрузки на БД
- Медленнее получение задач

## ✅ Решение

### Округление до кратного 50

**Примеры:**
```
Рейтинг 1331 → округляем до 1350
  rating_min = 1350 - 150 = 1200
  rating_max = 1350 + 150 = 1500
  Ключ: rmin_1200|rmax_1500

Рейтинг 1335 → округляем до 1350
  rating_min = 1350 - 150 = 1200
  rating_max = 1350 + 150 = 1500
  Ключ: rmin_1200|rmax_1500  ← Тот же ключ! ✅

Рейтинг 1342 → округляем до 1350
  rating_min = 1350 - 150 = 1200
  rating_max = 1350 + 150 = 1500
  Ключ: rmin_1200|rmax_1500  ← Тот же ключ! ✅
```

### Формула округления

```javascript
const roundedRating = Math.round(rating / 50) * 50;
```

**Примеры:**
- 1331 → Math.round(1331/50) * 50 = Math.round(26.62) * 50 = 27 * 50 = **1350**
- 1335 → Math.round(1335/50) * 50 = Math.round(26.7) * 50 = 27 * 50 = **1350**
- 1342 → Math.round(1342/50) * 50 = Math.round(26.84) * 50 = 27 * 50 = **1350**
- 1324 → Math.round(1324/50) * 50 = Math.round(26.48) * 50 = 26 * 50 = **1300**

## 📊 Диапазоны рейтинга

| Округленный рейтинг | Диапазон задач | Ключ кеша |
|---------------------|---------------|-----------|
| 1200 | 1050-1350 | `rmin_1050\|rmax_1350` |
| 1250 | 1100-1400 | `rmin_1100\|rmax_1400` |
| 1300 | 1150-1450 | `rmin_1150\|rmax_1450` |
| 1350 | 1200-1500 | `rmin_1200\|rmax_1500` |
| 1400 | 1250-1550 | `rmin_1250\|rmax_1550` |

## ✅ Преимущества

1. **Стабильные ключи кеша**
   - Рейтинг 1331-1349 → один ключ `rmin_1200|rmax_1500`
   - Кеш переиспользуется

2. **Меньше нагрузки на БД**
   - Кеш создается реже
   - Больше запросов из кеша

3. **Лучшая производительность**
   - Больше попаданий в кеш
   - Быстрее получение задач

4. **Приемлемая точность**
   - Диапазон ±150 остается
   - Задачи все еще подходят по уровню

## 🎯 Альтернативы

### Округление до 100 (более агрессивное)
```javascript
const roundedRating = Math.round(rating / 100) * 100;
```
- **Плюс:** Еще меньше ключей кеша
- **Минус:** Менее точное попадание (диапазон ±200)

### Округление до 25 (более точное)
```javascript
const roundedRating = Math.round(rating / 25) * 25;
```
- **Плюс:** Более точное попадание
- **Минус:** Больше ключей кеша

**Рекомендация:** Округление до 50 - оптимальный баланс.

## 📝 Реализация

Изменения в `backend/web/scripts/tasks/api.js`:

```javascript
if (TasksState.selectedMode.id === 'rated') {
    const rating = window.TasksUtils.getCurrentPuzzleRating();
    // Округляем до кратного 50
    const roundedRating = Math.round(rating / 50) * 50;
    const spread = 150;
    params.set('rating_min', Math.max(400, roundedRating - spread));
    params.set('rating_max', Math.min(3500, roundedRating + spread));
}
```
